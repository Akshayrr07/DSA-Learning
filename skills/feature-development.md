# Feature Development Skill Reference

This file points to the Antigravity configuration directory for feature development workflows.

**Configuration Path**: [SKILL.md](../.agents/skills/feature-development/SKILL.md)

---

## Behavior & Steps

1.  **Research**: Gather requirements, check existing components, schema, and API layout.
2.  **Plan**: Draft implementation details, identify file changes, specify required agents.
3.  **Confirm**: Stop and get explicit user approval before making any code modifications.
4.  **Develop**: Coordinate with Frontend, API, and Backend engineers.
5.  **Test**: Verify with typescript compilation, lint tools, and QA checks.
