# Bug Investigation & Repair Skill Reference

This file points to the Antigravity configuration directory for bug sweeping and repair workflows.

**Configuration Path**: [SKILL.md](../.agents/skills/bug-fix/SKILL.md)

---

## Behavior & Steps

1.  **Parallel Sweep**: Spawn up to 4 specialized agents to scan relevant layers (Frontend, API, Database, DevOps).
2.  **Trace & Plan**: Identify the root cause and draft a minimal, targeted fix plan.
3.  **Confirm**: Stop and get explicit user approval before modifying code.
4.  **Apply Fixes**: Coordinate Frontend, API, and Backend engineers to apply fixes.
5.  **Verify & Test**: Check changes via compiler, linter, and validation sweeps.
