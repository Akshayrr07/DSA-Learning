# Module 10: Dynamic Programming (DP)

Dynamic Programming is an algorithmic technique for solving optimization problems by breaking them down into simpler sub-problems and utilizing overlapping subsolutions.

## Key Approaches
*   **Top-Down (Memoization):** Solves recursively and stores computed solutions in a cache.
*   **Bottom-Up (Tabulation):** Builds a table iteratively starting from base cases.

## Classic Patterns
*   **Fibonacci Sequence**
*   **Longest Common Subsequence (LCS)**
*   **0/1 Knapsack**
